    ADM DASHBOARD · WEB BETA 0.5

    New Eden, in your browser.

    An unofficial web companion built from SMT’s regional map snapshot. ADM and development indexes come directly from CCP’s public ESI service and refresh about every five minutes while this page is open.

    Settings and the last public ADM response are saved in this browser. No account or access to local files is required. When enabled, alliance logos load from CCP’s image server.

    Map routes use the bundled stargate snapshot—not wormholes or jump bridges. Verify routes in game. N/A means no applicable sovereignty ADM; — means missing data. Amber ADM values are cached or unverified.

    Search supports full and partial system names. Routes use the bundled stargate snapshot.
